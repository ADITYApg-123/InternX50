InternX50 is a comprehensive, minimalist dashboard designed to keep you in the flow state and track your progress over a strict 50-day preparation roadmap. Stop consuming, start executing!

## ✨ Features & Mission Control

- **🎯 50-Day Roadmap Tracker**: Every day is precisely planned out, covering DSA, Core ML/DL, CS Fundamentals, and Mock Interviews.
- **📊 Analytics Dashboard**: Visualize your readiness score, track progress, and monitor consistency over time.
- **💻 DSA Tracker**: Systematically keep track of the Data Structures and Algorithms problems you've solved and topics you've mastered.
- **🧠 Core ML/DL Modules**: Keep your Machine Learning and Deep Learning concepts organized and track revisions.
- **🎤 Interview & OA Management**: Log and analyze your Online Assessments (OAs), mock interviews, and behavioral questions.
- **🛠️ Projects & Backlog**: Manage your portfolio projects and track pending tasks in an organized backlog.
- **🗓️ Schedule & Daily Reflections**: Document your daily learnings, blockers, improvements, and manage your schedule in one place.

## 💻 Tech Stack

InternX50 is built with modern web technologies to ensure a fast, responsive, and aesthetically pleasing experience:

- **Framework**: [Next.js 16.2+](https://nextjs.org/) (App Router)
- **UI Library**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Components**: [shadcn/ui](https://ui.shadcn.com/) & [Base UI](https://base-ui.com/)
- **State Management**: [Zustand](https://zustand-demo.pmnd.rs/)
- **Charts**: [Recharts](https://recharts.org/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/) & Tailwind CSS Animate
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

Follow these instructions to set up the project locally.

### Prerequisites

Make sure you have Node.js installed (v20+ recommended).

### Installation

1. **Clone the repository** (if you haven't already):
   ```bash
   git clone https://github.com/your-username/InternX50.git
   cd InternX50
   ```

2. **Install the dependencies**:
   ```bash
   npm install
   # or
   yarn install
   # or
   pnpm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   # or
   yarn dev
   # or
   pnpm dev
   ```

4. **Open the application**:
   Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📂 Project Structure

Here's an overview of the core application structure based on the `/src/app` directory:

- `/src/app/analytics` - Visualizations and readiness scores
- `/src/app/backlog` - Task and study backlog management
- `/src/app/dashboard` - Main mission control and overview
- `/src/app/dsa` - Data Structures & Algorithms tracker
- `/src/app/interview` - Mock interviews and behavioral questions
- `/src/app/ml-dl` - Machine Learning & Deep Learning curriculum
- `/src/app/oa` - Online Assessments tracker
- `/src/app/projects` - Portfolio and project management
- `/src/app/reflection` - Daily logs, blockers, and improvements
- `/src/app/roadmap` - The core 50-day master plan
- `/src/app/schedule` - Calendar and daily schedule
